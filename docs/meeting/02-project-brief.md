# Project Brief - DukyStore Client MVP

## Muc tieu san pham

Xay dung client web ban hang cho DukyStore de khach co the xem san pham, them vao gio, dat hang va tra cuu don hang ma khong can dang nhap.

## MVP success criteria

MVP duoc xem la dat khi flow sau chay end-to-end tren preview:

```txt
Homepage -> Product listing/category/search -> Product detail -> Add cart -> Cart -> Checkout -> Order success -> Order tracking
```

## Nguyen tac uu tien

- Uu tien flow ban hang truoc cac tinh nang noi dung/phu tro.
- BE la source of truth cho gia, ton kho, shipping fee, total va checkout validation.
- FE tap trung hien thi dung data, validate co ban, UX ro rang khi loading/error/empty.
- Khach mua hang theo guest checkout trong MVP.
- Online payment, account, wishlist, review, coupon, chatbot de Post MVP neu khong co chi dao moi.

## Pham vi P0

- Homepage.
- Product listing.
- Category products.
- Search/filter/sort co ban.
- Product detail.
- Product gallery.
- Variant selection neu API san sang.
- Add to cart.
- Cart page.
- Update/delete/clear cart.
- Checkout COD/bank transfer.
- Order success.
- Order tracking by order code.
- Responsive QA.
- Integration QA.
- Deploy preview.

## Pham vi P1

- Contact page.

- SEO rendering.

- UX polish.
- Image lazy load/performance basic.
- Accessibility basic.

## Pham vi P2/Post MVP
